# -| Признак | PP-LCNet (реальная) | TinyOrientationNet (моя) |
|---|---|---|
| **Базовый блок** | DepthSepConv (как у MobileNetV1) | Тот же тип блока — тут совпадает |
| **Активация** | H-Swish везде вместо ReLU (даёт заметный прирост точности почти без потери скорости) | Обычный ReLU |
| **SE-модули** | Есть, но только в блоках ближе к концу сети (на Intel CPU SE замедляет инференс, поэтому не по всей сети) | SE-модулей нет вообще |
| **Размер ядра свёртки** | В хвосте сети — 5×5, не только 3×3 | Везде 3×3 |
| **Слой после GAP** | Дополнительный увеличенный 1×1-conv после global average pooling перед классификатором | Сразу Linear после GAP, без промежуточного слоя |
| **Веса** | Предобучена на ImageNet, дообучена под текст | С нуля, случайная инициализация, без претрейна |
| **Реализация** | PaddlePaddle | PyTorch |
