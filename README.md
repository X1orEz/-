
        Для решения данной проблемы я сначала решил проверить, решали ли такую проблему до меня. Как оказалось нейросеть для решения данной задачи уже есть
        (PP-LCNet) и по заявлениям разработчика справляется очень хорошо. Сначала я взял эту готовую модель и попробовал засабмитить её результаты. Как 
        оказалось, если брать предобученную модель PP-LCNet, то она оказывается даже хуже угадывания, где у всех результатов было бы 0.5. Я решил, что это 
        возможно потому, что при обучении использовались данные, которые не подходят для нашего тест датасета. Поэтому я решил пойти другим путём. Упростить
        архитектуру нейросети, переписать её на torch. В таблице ниже есть отличия между моей реализацией и оригинальной архитектурой. Также я решил 
        проверить тестовый датасет, просмотрел около 50 фотографий, чтобы понять какие данные даются модели для сабмита. Понял, что фотографии мелкие, с 
        одним боксом текста, содержат цифры, латиницу, и бывают в плохом качестве. Я решил искуственно сгенерировать датасет для обучения и валидации 
        модели, потому что попытавшись найти хороший датасет в интернете, понял, что многие фотографии бывают по разному повёрнуты в пространстве, а не 
        только 0 или 180, это бы ухудшило модель. Плюс эти датасеты не такие большие, по сравнению с тем, какой получилась сгенерированная выборка. Также 
        для реализации этой идеи нужен большой набор шрифтов. Для этого нужно спарсить шрифты с google fonts поддерживающие кириллицу. Сама генерация 
        датасета занимает около 40 минут. Обучение модели около 30 минут на T4. Инференс модели на тестовых данных происходит очень быстро. Тестовые данные
        у меня лежат на гугл диске в папке images.


        | Признак           | PP-LCNet (реальная)             | TinyOrientationNet (моя) |
        |-------------------|---------------------------------|--------------------------|
        | **Базовый блок** | DepthSepConv (как у MobileNetV1) | Тот же тип блока — тут совпадает |
        | **Активация**    | H-Swish везде вместо ReLU (даёт заметный прирост точности почти без потери скорости) | Обычный ReLU |
        | **SE-модули**    | Есть, но только в блоках ближе к концу сети (на Intel CPU SE замедляет инференс, поэтому не по всей сети) | SE-модулей нет вообще |
        | **Размер ядра свёртки** | В хвосте сети — 5×5, не только 3×3 | Везде 3×3 |
        | **Слой после GAP**| Дополнительный увеличенный 1×1-conv после global average pooling перед классификатором | Сразу Linear после GAP, без промежуточного слоя |
        | **Веса**         | Предобучена на ImageNet, дообучена под текст | С нуля, случайная инициализация, без претрейна |
        | **Реализация**   | PaddlePaddle                      | PyTorch |
